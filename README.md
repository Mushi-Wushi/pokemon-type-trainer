# ⚔️ Pokémon Type Matchup Trainer

A battle-style quiz app to help trainers master Pokémon type effectiveness.

Pick the type that is **super effective** against the defending Pokémon type.  
Train your memory. Build your streak. Become a Pokémon Professor.

---

## 🎮 Gameplay

- You are given a defending Pokémon type.
- Choose the attacking type that is super effective.
- You have **3 lives**.
- The quiz lasts **10 rounds**.
- High scores are saved per mode.

---

## 🧠 Features

- Easy Mode (5 types)
- Hard Mode (all 18 types)
- Type-based color theming
- Watermark SVG type icons
- Streak counter
- Lives system (♥︎♥︎♥︎)
- Progress orbs
- Keyboard controls (1–4, Enter)
- Battle history log
- Persistent high score (LocalStorage)
- Pokémon-inspired battle UI

---

## ⌨️ Controls

| Key | Action |
|-----|--------|
| 1–4 | Select answer |
| Enter | Next question / Start / Restart |
